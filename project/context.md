# UGC 背景：历史资料

项目围绕《饥困荒野》UGC 编辑器的节点、预设、教学、视频和创作复用。用户偏好具体精炼，要求讨论时先讨论；改文件先看当前内容，保留用户手改，仅改指定范围。生成文件、自动检查、视觉与原生软件核验分别说明。

教学以功能为主，一课讲清一个功能并看到结果；涉及放置编辑、复制收藏、信号、文本、ID、随机掉落、蓝图、运算与判断，具体课程以当前表为准。入口突出最终关卡、玩法和模板，奖励次之，避免普通任务列表。教学面板恢复时核对真实分类、条目、正文和配图。

腾讯影游分镜关注原片时间、等待操作、每次点击/长按/滑动、操作反馈、逐句对话、停帧和剪辑衔接；真实截图对应标记，玩家交互标红。第一关信号召唤讲解人物为薇诺娜。齿轮时点曾有约 22 秒/23 秒分歧，需重新核对当前分镜和原片。

自定义预设包含编辑后的单个对象和多个节点、蓝图与关联组成的功能组合。账号保存收藏和关卡数据、社区内容下载及好友分享是协作诉求；入口、接口、权限、容量和兼容性待确认，不能写成已实现。《明日方舟：终末地》蓝图分享可作为沟通类比。

历史游玩设置 Demo 包含模式、时长、阵营、特质和敌人倍率；视觉未确认一比一。教学入口研究方向为创作学院、模板实验室等，突出作品效果、创作链路和开始入口。所有历史文件状态均需重新核对。

## 用户补充：项目和节点分类（2026-11-13）

项目为《饥困荒野》的 UGC。用户说明，素材和预设节点基本采用外部资源，UGC 特有的组件节点另作区分；所举例子包括老虎机、商品台、物理门、计时器、计数器，这些属于常规 UGC 功能，具体设计后续逐个细化。蓝图类以及用户刚才提到的这类节点都属于有功能的脚本节点。

“外部资源”的具体来源和范围，以及组件节点、预设节点、脚本节点之间完整分类关系仍待用户进一步明确；不擅自推断素材授权、全部归类或具体功能。
