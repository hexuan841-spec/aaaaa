# 自定义预设、收藏与复用
> 下列兼有历史已讨论方向和未来协作期望；不等于所有功能已经上线。

自定义预设可指已编辑的单个生物、武器、节点等，也可指框选保存的多个节点、蓝图及内部关联组成的功能组合。希望收藏后可拖出复用并继续修改；单个预设也希望能被其他节点选择，例如让召唤节点选用事先编辑的蜘蛛。

用户曾说明拖出后执行顺序 ID 自动填充、跨地图对齐已有优化，仍应在当前版本验证。腾讯协作希望将玩家收藏、社区下载收藏和关卡数据与账号关联保存，后续登录恢复；希望能展示、下载、导入内容并与好友分享。入口、接口、权限、容量、版本兼容及引用边界均待确认。

沟通时先说明是什么、为什么需要、玩家怎么使用、需要对方配合什么，再补具体例子。可用其他作品的蓝图保存和分享作为类比，不把类比作品的实现直接当成本项目能力。
