# 节点与逻辑：历史知识，实际情况须核对

信号：发送节点发信号，其他节点接收相同信号后响应。教学案例是感应开关发送、召唤节点接收并召唤蜘蛛与蛙腿三明治。流程蓝图包括开始、操作、发射信号等；值及逻辑判断提供数据供其他节点使用。不要猜端口数、执行顺序或程序解析规则。

值：读取并提供数据；赋值：修改指定目标的数据或状态；判断条件：比较参数得到结果；条件分支：根据条件结果选择后续逻辑。运算预设已存在，具体类型依当前界面。已有计数器、计时器、感应开关、逻辑和切换开关；召唤不限生物，也可能召唤物品及其他可配置预设。详见 existing-presets.md。

自定义预设可涵盖编辑后的单个对象和框选保存的多个节点、蓝图与内部关联。用户曾表示跨地图拖出后蓝图执行顺序 ID 可自动填充和对齐；需核对当前版本。

节点错误候选重点：必填缺失、数值越界、引用被删、类型不兼容、ID、信号及参数组合；没有目标或信号另一端可能是有意配置，不自动视作阻断错误。这是历史候选，不代表已实现。

历史建议命名：纠错入口 `UGC_error_guide`、错误 `UGC_error`、警告 `UGC_warning`、提示 `UGC_notice`。节点字段和表规则见配置手册，配置方案不代表程序已支持。
