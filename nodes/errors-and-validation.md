# 节点参数检查与提示：历史候选
> 是策划候选，并非现有报错清单或已实现功能；严重程度需逐项确认。

优先检查必填为空、数值越界、格式或类型不符、引用对象被删除、重复或无效 ID、节点参数不完整，以及信号、召唤、掉落、提交、商店、任务、文本、属性和蓝图的参数组合。

明确缺失、越界、引用失效和类型不兼容可作为错误候选；信号没有另一端、没有匹配目标、节点暂未连接等可能是玩家有意配置，应先评估是否提示或警告，不能一律阻断。提示应说明哪个节点、哪个参数、问题是什么；文案尽量短而具体。历史列名包含错误 ID、报错类型、关联组件 ID、显示权重、展示文本 ID 和分类，具体配置以当前模板为准。

历史命名建议：UGC_error_guide、UGC_error、UGC_warning、UGC_notice；最终名称依项目确认。
